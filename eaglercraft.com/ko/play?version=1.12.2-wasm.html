브라우저에서 즐기는 Minecraft

Eaglercraft는 브라우저에서 무료로 Minecraft를 플레이하는 방법이에요. 위에서 버전을 고르면 바로 이 탭에서 시작돼요. 다운로드도 설치도 필요 없고, 학교 Chromebook, 휴대폰, PC에서 차단 없이 돌아가요. Eaglercraft 서버에 접속하거나, 싱글플레이 월드를 공유 월드로 친구에게 열어 주거나, 리소스 팩으로 게임을 새롭게 꾸며 보세요.

도움말 및 FAQ

막혔나요? Discord나 r/eaglercraft에 물어보거나 시작 가이드를 읽어 보세요.

Eaglercraft가 뭔가요?

Eaglercraft는 학교 Chromebook을 포함해 일반 웹 브라우저라면 어디서든 돌아가는 오픈 소스 Minecraft예요. BungeeCord와 Velocity용 EaglerXServer 프록시 플러그인을 통해 실제 Minecraft 서버에 접속해요.

어떻게 작동하나요?

공식 런처처럼 Eaglercraft도 Mojang의 에셋으로 게임을 만들고, TeaVM으로 JavaScript로 컴파일해요. 프록시 플러그인이 브라우저의 WebSocket과 Minecraft의 TCP 프로토콜을 이어 주고, LAX1DUDE가 만든 호환 레이어가 고정 함수 OpenGL 렌더러를 WebGL 위에서 돌려요.

합법인가요?

Eaglercraft는 오픈 소스이고, DMCA로 보호되는 에셋은 저희가 호스팅하지 않아요. 공식 런처와 마찬가지로 Mojang 공식 서버에서 받아 와요. 권리자는 DMCA 페이지를 통해 연락할 수 있어요.

누가 만들었나요?

Eaglercraft는 2021년 말 LAX1DUDE가 만들었고, ayunami2000도 기여했어요. 이후 PeytonPlayz595, EymenWSMC, radmanplays 같은 커뮤니티 멤버들이 같은 기반으로 다른 버전을 포팅했어요.

싱글플레이

EaglercraftX 1.8은 내장 서버로 싱글플레이를 실행해요. 월드는 브라우저에 저장되고 오프라인에서도 작동해요. 기기 간에 옮기려면 EPK 파일로, 바닐라 Minecraft 1.8과 주고받으려면 ZIP 파일로 가져오기/내보내기 하세요.

공유 월드

싱글플레이 월드에서 일시 정지 메뉴를 열고 Invite를 누르면 공유 월드가 시작돼요. 참여 코드가 나오면, 친구는 Multiplayer → Direct Connect → Join Shared World로 가서 코드를 입력하면 돼요. 참여가 안 되면 모두 Network Settings에 같은 릴레이가 있는지 확인하세요. 다른 플레이어가 연 월드를 둘러볼 수도 있어요.

리소스 팩

바닐라 1.8 리소스 팩이라면 모두 쓸 수 있어요. zip 파일로 가져오면 브라우저에 저장돼요. 런처에서 향상된 음악/사운드를 켜면 오리지널 사운드트랙이 돌아오고, 리소스 팩을 둘러보고 클릭 한 번으로 추가할 수도 있어요.

음성 채팅

EaglercraftX 1.8에는 공유 월드와 음성 채팅을 켠 서버에서 쓸 수 있는 음성 채팅이 있어요. WebRTC를 사용하므로 상대방이 내 IP 주소를 볼 수 있다는 점에 유의하세요.

브라우저 호환성

JavaScript 런타임은 Chrome 38처럼 오래된 브라우저에서도 작동해요. WebGL 1과 2를 모두 지원하지만, 동적 조명과 셰이더는 WebGL 2가 필요해요. 터치스크린에서는 자동으로 터치 조작으로 바뀌고, 내장 OGG 디코더 덕분에 iOS에서도 소리가 나와요.

WebAssembly GC

WebAssembly GC 빌드는 약 50% 더 빠르지만, WASM-GC와 JSPI를 지원하는 브라우저가 필요해요. 브라우저가 지원하면 런처가 자동으로 추천해 줘요. 플레이할 때는 수직 동기화를 켜세요. 안 그러면 게임이 너무 빨리 돌아 입력 지연이 생길 수 있어요.

PBR 셰이더

EaglercraftX 1.8에는 빠른 레이트레이싱 반사를 지원하는 지연 방식의 물리 기반 렌더러와 내장 PBR 머티리얼 팩이 들어 있어요. Options → Shaders에서 켜세요. 부동소수점 렌더 타깃을 지원하는 WebGL 2가 필요해요.
