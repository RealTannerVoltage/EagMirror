Update - EaglercraftX 1.8 u53

Major performance improvements including optimized buffer streaming for Intel Chromebooks, reduced WebGL crashes, enhanced dynamic lighting FPS, and various bug fixes for audio and rendering systems.

广告

u53 Changelog

  • Redesigned buffer streaming for optimal performance on intel chromebooks
  • Significantly reduced the likelyhood of "WebGL context loss" crashes
  • Significantly improved the FPS when dynamic lights are enabled
  • Use glDrawRangeElements when possible
  • Use ArrayBuffer.slice when possible
  • Fixed hissing noise on u52 with some audio chipsets
  • Fixed crash reports not showing throwable's causes
  • Fixed a bug when parsing GameProfile model type field
  • Fixed a bug with the EPW loader
