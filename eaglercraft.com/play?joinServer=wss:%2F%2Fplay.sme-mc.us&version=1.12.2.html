Help and FAQ

Stuck? Ask on Discord or r/eaglercraft, or read the getting started guide.

What is Eaglercraft?

Eaglercraft is an open source Minecraft that runs in any regular web browser, school Chromebooks included. It joins real Minecraft servers through the EaglerXServer proxy plugin for BungeeCord and Velocity.

How does it work?

Like the official launcher, Eaglercraft builds the game from Mojang's own assets and compiles it to JavaScript with TeaVM. A proxy plugin bridges the browser's WebSocket to Minecraft's TCP protocol, and a compatibility layer by LAX1DUDE runs the fixed-function OpenGL renderer on WebGL.

Is this legal?

Eaglercraft is open source, and assets protected under the DMCA are not hosted by us: they come from Mojang's official servers, as with the official launcher. Rights holders can reach us through the DMCA page.

Who made this?

Eaglercraft was created by LAX1DUDE in late 2021, with contributions from ayunami2000. Community members such as PeytonPlayz595, EymenWSMC and radmanplays have since ported other versions on the same foundation.

Singleplayer

EaglercraftX 1.8 runs singleplayer on an integrated server. Worlds are saved in your browser and work offline. Import and export them as EPK files to move them between devices, or as ZIP files to and from vanilla Minecraft 1.8.

Shared worlds

Open the pause menu in a singleplayer world and press Invite to start a shared world. You get a join code; friends go to Multiplayer, Direct Connect, Join Shared World and enter it. If joining fails, check that everyone has the same relays under Network Settings. You can also browse worlds other players are hosting.

Resource packs

Any vanilla 1.8 resource pack works: import it as a zip and it is saved in your browser. Turn on Enhanced Music/Sounds in the launcher to add the original soundtrack back, or browse resource packs and add them in one click.

Voice chat

EaglercraftX 1.8 includes voice chat for shared worlds and for servers that enable it. It uses WebRTC, so be aware that peers can see your IP address.

Browser compatibility

The JavaScript runtime works on browsers as old as Chrome 38. WebGL 1 and 2 are both supported, though dynamic lights and shaders need WebGL 2. Touch screens switch to touch controls automatically, and an embedded OGG decoder keeps audio working on iOS.

WebAssembly GC

The WebAssembly GC build runs around 50% faster but needs a browser with WASM-GC and JSPI. The launcher offers it automatically when your browser supports it. Turn on VSync when you play it, or the game can run too fast and cause input lag.

PBR shaders

EaglercraftX 1.8 ships a deferred, physically based renderer with fast raytraced reflections, plus a built-in PBR material pack. Enable it under Options → Shaders. It needs WebGL 2 with floating-point render targets.

Making a server

Use EaglerXServer by lax1dude, then list your server so players can find it.
